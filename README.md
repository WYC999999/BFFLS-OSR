## 📝 2. 制度细则（使用 / 停放 / 充电 / 巡查）

### 4.1 电动自行车使用规范

1. 禁止任何形式的非法改装，包括但不限于：

   * 提升电机功率
   * 加装副座
   * 更换超标电池
   * 拆除限速装置
2. 学生骑行必须佩戴安全头盔。
3. 不得在人行区域内骑行、飙车、追逐或进行危险动作。

### 4.2 停放管理制度

1. 校内仅允许在指定区域停放。
2. 禁止随意停在人行道、教学楼入口等区域。
3. 停放需整齐、按编号排列。

### 4.3 充电管理制度

1. 禁止在宿舍、教室等区域私自充电。
2. 使用学校指定的智能充电桩。
3. 夜间禁止无人值守长时间充电。
4. 发现电池鼓包、过热应立即停止使用。

### 4.4 巡查制度

* 每周开展 2 次常规巡查。
* 对违规改装、乱停乱放、危险充电等情况进行记录。
* 严重问题立即上报。
* 巡查记录需归档。
