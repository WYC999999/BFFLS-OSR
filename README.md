# 红警怪谈（Red Alert Creepypasta）

> 以下规则来自一位沉迷《红色警戒》到近乎失控的玩家所留下的记录。  
> 他的名字已经不再重要，因此以下内容只称呼他为 **“那个人”**。  
> 如果你决定运行《红色警戒》，请务必遵守以下规则。

---

## 红警怪谈规则

**1.**  
运行《红色警戒》的电脑 **运行内存必须大于 128GB**。  
如果你的电脑低于此数值，请立即关闭游戏。  
有玩家曾尝试在 16GB 内存上运行，后来他说地图里多出了一个从未被编写的阵营，即 **丰台区外国语** 。

---

**2.**  
显卡必须为 **RTX 5080 或以上型号**。  
如果游戏启动时出现任何 **显卡性能过低**，不要点击“开始游戏”，  
也不要截图。  
据说截图会留下某种 **坐标信息** 并发送给黄仁勋。

---

**3.**  
鼠标必须为 **青轴鼠标**。  
众所周知，青轴是键盘常见的轴体，但当尝试游玩《红色警戒》时，务必使用装有青轴的鼠标进行游玩，原因不明。如果你没有青轴鼠标，请立即退出游戏，或用尽可能快的速度拆下鼠标原有的微动开关并通过工具将青轴上的引脚焊接到鼠标上并盖上键帽。

---

**4。**  
任何设备上的《红色警戒》**都不允许卸载**。  

无论是：

- 家用电脑  
- 学校机房电脑  
- U 盘  
- 甚至包括 **希沃白板**
