# 校园异常物品登记档案  
**Campus Anomalous Objects Registry (CAOR)**

本分支专注于系统性收录、登记与归档在学校（校园）环境中确认存在的异常/奇异物品。

所有条目须满足以下核心标准：
- 物品的出现、效应或传说源头与特定学校空间高度绑定
- 已获得至少一份可验证的目击、使用或影响记录
- 非纯都市传说或外部传入物品

## 登记编号规则
- 格式：CAOR-XXX（三位数字，从001起顺序递增）
- 如需细分，可扩展为 CAOR-XXX-A/B 等

## 登记规范（推荐）

1. **中文名称**：建议5–8个汉字，风格偏中性、描述性或机构化（如“XX教学楼异常镜面”）
2. **英文名称**：采用“Anomalous [Object Type] - [Descriptor]”格式，或直接机构式命名
3. **物品类型**：建议分类如“Spatial”、“Cognitive”、“Temporal”、“Mimetic”、“Physical”等
4. **故事/事件描述**：控制在150–500字，包含发现过程、影响记录、当前状态等
5. **登记日期**：使用真实或设定内的日期，增强档案真实感

欢迎贡献符合标准的条目。提交前请确保物品具备可追溯的校园关联性。
